# Family Menu MVP

Приложение на русском языке для составления бюджетного семейного меню с учётом вкусов взрослых и детей.

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000)

## Сборка

```bash
npm run build
npm start
```

## GitHub Pages

Проект настроен на статический экспорт (`next build` -> папка `out`) и автодеплой через GitHub Actions.

1. Убедитесь, что основной branch — `main`.
2. В репозитории откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Source: GitHub Actions**.
4. После push в `main` workflow `.github/workflows/deploy-pages.yml` соберет и опубликует сайт.

Для этого репозитория сайт будет доступен по пути:
`https://victoriiamikhaleva.github.io/feeding-managment/`

## Возможности

- Главная страница с описанием преимуществ и историей меню
- Форма с шаблонами, валидацией и загрузкой сохранённого профиля
- Генерация меню с разнообразием и учётом аллергий (лактоза, глютен…)
- Замена отдельного блюда (↻) без перегенерации всего меню
- Список покупок с чекбоксами и умным объединением ингредиентов
- План заготовок, сезонные подсказки, обеды на работу
- Вкладки: Меню / Покупки / Советы
- Копирование меню и списка, печать
- История до 20 меню на странице `/history` с удалением
- Drag-and-drop перестановка дней на странице результата
- PDF в стиле wellness-guide: одна страница = один день, 3 колонки (завтрак/обед/ужин)
- Голосовой ввод через Web Speech API (локально)

## Страницы

- `/` — главная
- `/form` — заполнение анкеты (ручной/голосовой ввод)
- `/result` — готовое меню, список покупок, PDF
- `/history` — история сохранённых меню
