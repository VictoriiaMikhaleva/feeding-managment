# Семейное меню на неделю

MVP-приложение для составления бюджетного семейного меню с учётом вкусов взрослых и детей.

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000)

## Сборка

```bash
npm run build
npm start
```

## Возможности

- Главная страница с описанием преимуществ
- Форма составления меню (ручной и голосовой ввод)
- Генерация меню на 1–14 дней
- Список покупок по категориям
- План заготовок и подсказки по экономии
- Сохранение в localStorage
- Голосовой ввод через Web Speech API (локально, без сервера)

## Стек

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4

## Дисклеймер

Меню носит рекомендательный характер. При аллергиях и медицинских ограничениях проконсультируйтесь со специалистом.
